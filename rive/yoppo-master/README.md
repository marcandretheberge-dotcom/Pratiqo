# Yoppo neutral master v1

First vector reconstruction of the canonical YoPratiqo companion.

This project intentionally contains **no walking, victory, production app integration or payment/learning state**.
It exists to prove that the canonical idle Yoppo can be rebuilt as editable Rive vector geometry on the frozen
1024×1024 artboard while preserving its identity.

The default frame is the neutral construction rest pose:
- body/ground anchor at x=512, y=920;
- canonical slight 3/4 explorer orientation;
- feet flat;
- shoulders level;
- arms slightly opened for complete hidden geometry;
- neutral mouth/open eyes;
- backpack offset remains visible on viewer-right.

The existing production PNG remains the runtime fallback until this master passes the overlay gate and later review.
