# Personalized Italian pilot · 2026-11-07

## Scope
The existing Italian guided routes now use a reusable entry flow. Onboarding asks experience, purpose and weekly time, offers a bounded adaptive placement check or a manual starting unit, and remembers the choice on this device. Time changes pace, never level. Goal appears in the plan; it does not pretend to generate a new AI-authored curriculum or to replace prerequisites.

The first unit is rewritten around greetings/names/how someone is, origin/nationality, and age. Each mission starts with four illustrated choices per vocabulary item, then uses the existing guided learning sequence. The first unit has 17 visual targets, 19 exercises and a five-question independent final. Later Italian units retain their existing authored curriculum, now in the same keyboard-free guided renderer, including controlled café/map drafts. The new four-image vocabulary packs are authored for unit 1 only; other languages are not changed.

The complete first-unit translated word/verb bank is available before starting, both in the notebook and at `/yo/langues/italien/parcours/u01/vocabulaire?lang=fr` (also en/es). It includes all taught vocabulary expressions, four verb families, functional words, and a 0–30 number reference. Other units expose their existing phrase/example banks, not a newly authored exhaustive word-by-word lexicon.

## Evidence and access
- Profile and placement state are local navigation guidance, not paid access entitlements.
- Starting later or revising earlier units awards no stamps, points or credits and consumes no Pass.
- No checkout, booking, Stripe, database, authentication, teacher-sharing or credit mutation is introduced. This pilot retains the existing public course access state. Do not attach paid content to local placement flags.
- Pratiqo Match remains an explicit link to the real Italian teacher search. No learner answers are sent to teachers.
- New first-meeting IDs cannot inherit the previous sound-course stamp. The previous `yo.italian` course record is not overwritten. Known unchanged later-unit outcomes are copied once into a versioned new course record.
- Onboarding/preferences and new UI state are browser-local, not cross-device sync. Unavailable storage is disclosed.

## Audio
Existing exact recordings are reused, including every assessed listening stimulus. New authored expressions without a recorded path use an explicitly labelled Italian device-voice preview fallback; no English fallback and no paid TTS request. Where the device has no Italian voice, vocabulary offers a visible read-instead route and practice remains usable. This is not a claim that every new phrase has a published studio recording. Complete new recorded-audio publication and iOS/Android checks remain production-release requirements.
