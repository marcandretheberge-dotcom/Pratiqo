# Bois doux success feedback — review increment

Original sound A is synthesized with the approved two-note wooden timbre (587.33 Hz then 783.99 Hz), the same envelopes and moderate 0.22 peak. No third-party media, new dependency, TTS call or network request is used. A three-note variant marks a passed unit.

## Coverage
The personalized Italian entry wraps all 12 guided Italian units and placement in a shared cosmetic feedback provider. A checked correct vocabulary image, correct exercise, every matched pair and each successful dialogue turn emits once. The last pair/turn does not double-trigger aggregate scoring or sound. Corrected practice receives positive feedback without changing mastery rules. Selecting an answer, an incorrect answer, mounting, restoring a draft, opening the notebook and revisiting a result do not emit success sounds.

Yoppo uses the existing celebrating artwork with a short, reduced-motion-aware appearance. This is not a new articulated note-taking character animation.

## Preferences and interruptions
New learners hear success sounds after their first validated user action. The prior `yopratiqo.audio.muted=true` choice is respected. Sound and vibration switches are independent, stored locally, visible during onboarding and in Yoppo's tools. Pronunciation controls are independent. Blocked storage is disclosed as session-only. Vibrations default off and use a supported navigator.vibrate call only. Unsupported browsers show that state; no hidden input workaround. iPhone Safari native haptics require future app integration and are not claimed here.

Audio lifecycle leases cover recordings (including buffering) and the Italian speech-synthesis fallback. Success cues never stop lesson audio; at most the latest cue waits up to 2.5 seconds for speech to end. Navigation, hidden pages, mute, a new recording and unmount cancel stale feedback. Feedback failure never blocks learning. This cosmetic layer has no progress, pass, credit, payment, teacher-data or database writes.
