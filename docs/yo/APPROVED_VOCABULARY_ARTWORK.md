# Approved vocabulary artwork · 7 November 2026

## Scope
The founder approved three illustrated vocabulary-screen mockups and explicitly requested integration and deployment. This change places six individual illustrated card regions into the real first-unit Italian vocabulary player. It does not install a screenshot of an app or replace native text, controls, scoring, audio or the canonical Yoppo artwork.

The art registry and presentation component are reusable. Only the Italian first-unit visual bank is wired to this release. The other language curricula and an Expo binary are separate work; this is not represented as completing those deliveries.

Coordinates refer to the 941×1672 source mockups. Insets remove the phone/UI frames, buttons, progress and card borders. AVIF files preserve the individual illustration, not UI text or an invented face. They total 50,288 bytes. Next/Image serves appropriately sized images and a negotiated output format. The source art is intentionally bounded to mobile-card resolution, not claimed to be new high-resolution original masters.

Character names, ages, city and nationality facts are actual localized interface text. Identity questions rely on fictional stated information, never facial appearance. The baked birthday cake labelled 18 is not reused for ages 20/21/28/30. The second smiling traveller is not used as a distractor to “Sto bene”. For the existing feeling activities, a coffee scene replaces the old sleeping distractor; its non-answer option ID `asleep` is retained to preserve saved choices. All 17 word IDs, correct targets, audio text, word order, completion and rewards are unchanged.

The presentation projection does not mutate original curriculum records. A missing image exposes its localized alternative description without blocking the question. Selection has an outline; a success check appears only after a correct answer is actually validated. No added permissions, external image service, tracking, payment, Pass or database mutation.
