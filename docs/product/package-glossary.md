## Approved terms

| Term | Intent |
|------|--------|
| Forfait proposé par le professeur | Package is teacher-offered, not platform-owned |
| Séance | A session / lesson unit |
| Séance complétée | Delivered / completed session |
| Séance non utilisée | Unused / undelivered session |
| Crédit lié à ce professeur | Phase 2 — balance tied to one teacher |
| Paiement facilité par Pratiqo | Intermediary payment facilitation |
| Frais de plateforme | Platform fee (not “salary” language) |
| Solde non utilisé | Remaining unused value/sessions |
| Remboursement du solde applicable | Refund of applicable unused balance |
| Versement au professeur après les séances complétées | Progressive payout |

English / Spanish UI should mirror the same marketplace positioning (teacher-offered package, facilitated payment, progressive payout).

## Quick checks before shipping copy

1. Could this sentence still be true if Pratiqo were only software + payments?  
2. Does it imply employment, assignment, or outcome guarantees?  
3. Does it imply a Pratiqo-owned hour bank that expires?
